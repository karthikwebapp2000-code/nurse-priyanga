## Folder Structure
```
priyanga-v2/
├── index.html              ← Main website (single-file)
├── assets/
│   ├── css/
│   │   └── style.css       ← (extracted styles — optional)
│   └── js/
│       └── main.js         ← (extracted scripts — optional)
└── data/
    ├── competition.json    ← Competition categories, timeline, prizes
    └── hospital.json       ← Kauvery Hospital partner data
```

## Features
- Loading animation on page open
- Pivot-style animated nurse character (CSS GIF-style)
- Kauvery Hospital partnership section
- Registration form
- Scroll reveal animations
- Custom cursor
- Mobile responsive

## Deploy to Vercel
1. Upload this folder to GitHub
2. Import repo on vercel.com
3. Deploy — no build step needed (static HTML)
